# ElabMedia — публичные плейлисты и выпуски

Содержимое по умолчанию для публичной сборки ElabMedia (`com.elab.hub.pub`):

- `playlist/def_tv.m3u` — ТВ-плейлист: российские каналы в открытом доступе, только потоки самих
  вещателей (их сайты и CDN), без перезаливов. Подбирались по каталогу iptv-org с проверкой
  живости (html-viewer: `audit/probe.mjs`);
- `logos/` — логотипы каналов, которых нет в epg.one (у остальных — `epg.one/img/<id>.png`);
- ветка `epg` — свой гид программы передач, собирается каждые 6 часов workflow EPG
  (`tools/build_epg.py` по таблице `epg/sources.json`) только по каналам плейлиста;
- `playlist/default.m3u` — радио-плейлист;
- `config/elabmedia.json` — удалённый конфиг (способ добывания видео YouTube);
- **Releases** — сборки приложения с тегами `elabhub-<версия>`. Приложение само находит здесь
  новые версии и предлагает их установить.

Правка файлов в этом репозитории доходит до всех установленных приложений без переустановки.
